Setting up the project:
- Go to Github project > Code > copy Link
- Go to Terminal, go to the right directory
  (use 'ls' to see list, use 'cd' to change directory )
- git clone [insert link]
- start VSCodium > Open Folder > (choose the folder)
- in VSCodium, go to Extensions > Live Server/ Five Server > Install 
  (this is to see the changes live, of ex websites, bottom right there's a 'Go Live' button)
